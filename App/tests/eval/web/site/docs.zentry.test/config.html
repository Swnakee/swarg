Configuration reference

Zentry reads zentry.toml from the working directory. Each key is listed with its type and default.

listen_addr

Type: string or number. Default: depends on the platform. This key controls the listen_addr behaviour of the server. Changing it requires a restart unless the server runs with reload enabled. See also the related keys in this section and the tuning guide for advice on production values.
